# Smart Campus Placement System

Java project to manage 1000 students and recommend jobs based on their skills and CGPA.

## Features
- Manage 1000+ Students data
- Job Recommendation based on Skills
- Search Student by ID
- Filter by Branch / CGPA

## How to Run
javac Main.java
java Main

## Technologies Used
Java, OOP, File Handling
